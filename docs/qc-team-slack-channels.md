# QC Team Slack Channel Structure — E-763 Morava Corridor

> Proposed Slack channel setup for the Quality Control team on the **E-763 Morava Corridor** highway project (Serbia).
>
> **Note:** These channels must be created inside the Slack app by a workspace admin — they cannot be created from this repository. This document is the plan to copy from. In Slack: **+ (Add channels) → Create a new channel** for each name below, then set the description and invite the relevant members.

## Naming convention

- Prefix every QC channel with `qc-` so they group together in the sidebar.
- Use lowercase and hyphens (Slack requirement).
- Keep discipline channels separate from process channels.

## Discipline / work-area channels

| Channel | Purpose |
|---|---|
| `#qc-earthworks` | Embankment, cut/fill, subgrade, compaction (proctor/CBR) tests, layer approvals by chainage. |
| `#qc-concrete` | Concrete works — mix designs, slump/cube tests, curing, rebar inspections. |
| `#qc-asphalt` | Bituminous layers — mix, Marshall/temperature checks, laydown and compaction results. |
| `#qc-drainage` | Culverts, pipes, ditches, geotextiles — installation and material checks. |
| `#qc-bridges-structures` | Bridges, viaducts, retaining structures — bearings, prestressing, structural inspections. |
| `#qc-materials-cert` | Material certifications, delivery notes, source approvals, aggregate/cement/steel certs. |

## Process / cross-cutting channels

| Channel | Purpose |
|---|---|
| `#qc-general` | Team-wide announcements, scheduling, general coordination. |
| `#qc-ncr` | Non-conformance reports — logging, tracking, and closeout. |
| `#qc-lab-reports` | Lab and field test results distribution and discussion. |
| `#qc-inspection-requests` | Inspection Requests / RFIs and inspection scheduling with the contractor/engineer. |
| `#qc-documentation` | Checklists, QC reports, ITPs, and quality documentation review. |
| `#qc-standards-specs` | SRPS, EN Eurocodes, PGBT, and project Technical Specification references and questions. |

## Suggested per-channel setup

For each channel, when creating it in Slack:

1. **Topic:** one-line scope (from the table above).
2. **Description:** add applicable standards / test frequencies where relevant.
3. **Members:** invite the responsible QC engineers/inspectors for that discipline; keep `#qc-general` for the whole team.
4. **Pinned message:** pin the relevant checklist/ITP or the NCR log link.
